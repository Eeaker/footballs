# Prototype verdict

## 2026-08-21 U12 verdict

- 本地与远端均自动选择 2 个主颜色簇，大小为 25/18。
- 自动层次聚类与现有固定 K=2 的 43 个 ID 分区完全一致，仅簇编号相反。
- 6 个已有号码确认 ID 全部按白/黄两队正确分开；确认数据只用于事后对照。
- 仅增加簇数并不好：K=3 形成 25/17/1，K=4 形成 23/17/2/1，整体轮廓分数下降。
- 两簇内部的 Tukey 距离异常检测在本地和远端稳定识别 ID 37（红）、39/41（黑）、42（灰）为特殊颜色或低质量轨迹。
- ID 31 只在本机 OpenCV 4 环境被判异常，在远端 OpenCV 5 未复现，暂列边界不稳定项。

结论：不要用“自动更多簇”替换现有两主队结构；值得吸收的是“主队 K=2 + 自动簇内异常拒识”，
避免裁判、门将或严重遮挡轨迹被强制写入传球网络。正式接入前需固定 OpenCV 版本并确定异常项处理策略。

第二轮纯 Tukey 阈值在本机误拒 ID 31；多帧身份墙确认它是正常黄队球员。阈值已改为
`max(Tukey fence, 15% × 两主队中心距离)`，避免簇内分布过紧导致正常色差被误杀。

保守阈值重跑后，本地稳定异常为 37/39/41/42，与远端一致。将它们标为 `unassigned`
重跑 match analysis：2213 个稳定球权证据帧、201 个片段、62 次转换和 6 条传球均不变。
