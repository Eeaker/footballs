# Identity Audit

该模块对技术 ID 的外观模式和局部切换进行质量审计。它的输出是**待复核候选**，不会自动改写正式 tracking MOT。

核心思路：

1. 从人物框的上半身球衣区域提取质量门控后的颜色/外观特征；
2. 对遮挡、低信息、小框等情况拒绝判定；
3. 学习主要队伍外观模式并保留 unknown；
4. 只有持续、纯度足够的跨模式变化才输出候选；
5. 同队同色球员之间的错误合并仍需要其他证据或人工检查。

`mode_split/` 包含门控、开放集队伍模式和 transition 状态机；`tests/` 覆盖核心回归。球衣特征直接复用 `engine/tracking/tracking_lib/team_features.py`，不保存副本。
